# Perfil offline cl100k_base

`Python 3.13.13`, `tiktoken==0.12.0`, `regex==2026.9.29`. O runtime fixa também o serializer da biblioteca padrão. Essa combinação foi verificada com wheel nativo local; não é uma afirmação sobre incompatibilidade de outras versões Python. Nenhum download em execução: o construtor recebe o arquivo local, após SHA-256. O arquivo `.tiktoken` reúne bytes do vocabulário e ranks das merges BPE; não há segunda fonte de merges.

Asset oficial: [cl100k_base.tiktoken](https://openaipublic.blob.core.windows.net/encodings/cl100k_base.tiktoken). SHA-256 esperado `223921b76ee99bde995b7ff738513eef100fb51d18c93597a113bcffe865b2a7`, publicado pelo [construtor oficial da versão 0.12.0](https://github.com/openai/tiktoken/blob/0.12.0/tiktoken_ext/openai_public.py). Configuração extraída dessa versão: pattern, tokens especiais, policy e versões registrados em `cl100k-config.json`, cujo hash canônico participa do fingerprint. A [licença MIT upstream](https://github.com/openai/tiktoken/blob/0.12.0/LICENSE) está preservada em `LICENSE.tiktoken`; notices acompanham a dependência e configuração vendorizada.

`reference-vectors.json` congela os resultados da implementação fixada para texto vazio, ASCII, Unicode composto/decomposto, CRLF, delimitadores/ferramenta e base64 binário. Os testes comparam os mesmos vetores ao construtor upstream com loader substituído apenas pelo asset local, sem acesso de rede. `hello world → [15339, 1917]` também está fixado no teste. Estes vetores não são recibos nem prova de formato de um provedor.

O serializer é JSON UTF-8 canônico com keys ordenadas, `ensure_ascii=false`, separadores `,`/`:`, sem normalização Unicode e sem truncamento adicional. A projeção preserva texto UTF-8 válido; bytes inválidos são base64 explícito. Captura truncada permanece um prefixo identificado com observado/capturado/truncado. Marcadores especiais são texto comum, nunca tokens de controle. O sidecar armazena os bytes serializados e hash próprios. A contagem é exata exclusivamente nesse perfil/payload controlado; não é `model_tokens` do histórico, uso faturado, formato de chat nem preço real.
